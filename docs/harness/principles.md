# 原則 — このハーネスが何を前提にしているか

同梱 skill が繰り返し参照する 3 つの原則。すべて実運用の事故から出ています
（各事故は [`incidents.md`](incidents.md)）。

---

## P1 — 自己申告禁止（No Self-Report）

**エージェント自身の「できました」を、完了の根拠にしない。**

エージェントは自分の出力を評価する立場に立つと、ほぼ必ず甘くなります。これは
プロンプトの品質では解けません。「十分やった」という判断は、判断する主体が
作業した主体と同じである限り、構造的に信用できないからです。

したがって停止判定は**作業した主体の外側**に置きます。具体的には終了コードです。

```
❌ エージェント「カバレッジは十分です」        → 採用しない
✅ gate が exit 0 を返した                    → 採用する
```

実測例: あるゴール到達型ループで、エージェントの自己判定は「90% 以上達成」と
宣言しました。決定論ゲートで測ると実測 55.9%（テストがコンパイルすら通っていない）。
同じループにゲートを噛ませた結果 98.3% で停止しました。

**このハーネスの全 skill は、この原則の実装です。**

---

## P2 — 停止は決定論で判定する（Deterministic Stop）

**「もう十分」の判定に LLM を呼ばない。**

P1 の系。検査そのものに LLM を使うと、同じ入力に対して違う答えが返り、
ゲートが「その日の機嫌」になります。ゲートは同じ入力 → 同じ出力でなければ、
回帰の検知に使えません。

同梱エンジンは全て:

- **Python3 標準ライブラリ / POSIX shell のみ**（外部 API 呼び出しなし・ネットワーク不要）
- **同じ入力 → 同じ出力**
- **`--self-test` を内蔵**（hermetic・一時ディレクトリの fixture のみ・実データに触れない）

`--self-test` は「ハードコードされた成功」を禁じます。各エンジンは最低限
**(a) 違反ありの fixture を検出できること** と **(b) 対象が存在しない場合に
「対象無」を明示して exit 0 すること** の両方を assert します。後者が無いと、
検査対象を 1 件も見ていないゲートが緑を返します（[`incidents.md#静かなゼロ`](incidents.md)）。

### 終了コード規約

| code | 意味 |
|---|---|
| `0` | 合格、または「対象無・観測継続」 |
| `1` | 違反あり（`findings` に列挙） |
| `2` | 引数不正 / I/O エラー。**0 件と解釈してはいけない** |

`2` を `0` と同一視すると、検査の失敗が合格に化けます。これは実際に起きます。

---

## P3 — 承認境界は「可逆性 × 外部到達 × 金銭/法的」で決める

**「重要そう」「技術的に重い」で承認レベルを決めない。**

人間の承認を挟む場所を直感で決めると、承認は「面倒な作業の前」に付き、
本当に危険な操作（権限・secret・DNS・本番データ）が素通りします。

| Level | 判定 | 扱い |
|---|---|---|
| **L1** | 可逆 × 内部完結 × 非金銭非法的 | 即時実行 |
| **L2** | 内部×不可逆 **or** 外部×可逆 | 事後報告 |
| **L3** | 金銭 / 法的拘束 / self-lockout（権限・secret・監視・DNS・runtime env）/ 本番データ破壊 / 外部 broadcast | 事前承認 |

2 つの補足規則:

- **可逆性は実測で証明する**（エージェントの自己申告で「可逆です」と言わせない = P1）
- **harness gate ⊇ policy** — fail-closed なフックが L1 の操作を止めたら、
  policy 側を緩めて通すのではなく人間に上げる。ゲートを policy に合わせて
  緩める運用を一度でも許すと、ゲートは以後ただのログになります。

同梱の `destructive-env-guard` は、この L3 集合が実際にフックで塞がれているかを
読み取り専用で監査します（フックは改変しません）。

---

## 3 原則の関係

```
P1 自己申告禁止 ── なぜ    ─→ 人は/AIは自分の仕事を甘く採点する
      │
      ├─ P2 決定論停止 ── どうやって ─→ exit code で外から判定する
      │
      └─ P3 承認境界   ── どこまで   ─→ 機械に任せる範囲を可逆性で切る
```

P2 の無い P1 は精神論、P3 の無い P2 は暴走します。3 つで 1 組です。
